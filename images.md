## Что подготовить (реальные скриншоты — главное)

Кладите в `img/` под этими именами — подставлю в слайды. Любое соотношение сторон: скриншот показывается по клику почти на весь экран, пропорции сохраняются. Без личных данных и ключей на экране.

|-------|------|------------------|
| 2. Идея и код | `img/step1-code.png` | Xcode или Android Studio, рядом чат/агент, который пишет код. Хорошо, если видно запрос словами и получившийся код |
| 3. Экраны | `img/cryptolife-figcraft.png` | ✅ уже есть — карта экранов Crypto Life в FigCraft |

| 8. Мои приложения | `img/app-2speak.png`, `img/app-cryptolife.png`, `img/app-game2.png` | Иконки трёх приложений (квадрат, 512×512+) |

### Слайд 6 — Айсберг

| Где | Сейчас | Картинка |
|-----|--------|----------|
| Верхушка | 📱 | Телефон с приложением (или реальный скриншот приложения) |
| SDK | 🧩 | Кубики-пазлы, вставляемые в телефон |
| Интеграции | 🔌 | Штекеры, подключённые к телефону |
| MMP | 🔗 | Хаб, в который сходятся линии от рекламных сетей |
| Реклама | 📣 | Рупор (или настоящие логотипы Google Ads / Meta — не генерировать) |
| Юнит-экономика | 💰 | Весы: стоимость пользователя против дохода с пользователя |
| Дистрибуция | 📡 | Каналы, по которым приложение доходит до людей |
| Удержание | 🧲 | Магнит, который держит пользователя |
| Возвращение | ↩️ | Стрелка, возвращающая пользователя в приложение |

### Слайд 7 — Внимание

| Где | Сейчас | Картинка |
|-----|--------|----------|
| Бабушка из Бразилии + GPT | 👵💻 | Бабушка за ноутбуком, на экране чат и готовое приложение |
| Иконки приложений | фиолетовые квадраты | Можно оставить: одинаковость — это и есть смысл |
| Глаз | 👁 | Глаз или прожектор, который выхватывает одно приложение |
