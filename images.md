# Картинки и скриншоты

## Что подготовить (реальные скриншоты — главное)

Кладите в `img/` под этими именами — подставлю в слайды. Любое соотношение сторон: скриншот показывается по клику почти на весь экран, пропорции сохраняются. Без личных данных и ключей на экране.

| Слайд | Файл | Что на скриншоте |
|-------|------|------------------|
| 2. Идея и код | `img/step1-code.png` | Xcode или Android Studio, рядом чат/агент, который пишет код. Хорошо, если видно запрос словами и получившийся код |
| 3. Экраны | `img/cryptolife-figcraft.png` | ✅ уже есть — карта экранов Crypto Life в FigCraft |
| 4. Интеграции | `img/step3-events.png` | События в дашборде: Firebase DebugView, AppsFlyer, Adjust — где видно, что событие из приложения дошло |
| 5. Стор | `img/step4-locales.png` | App Store Connect / Google Play Console со списком локализаций, или String Catalog в Xcode с 50 языками |
| 6. Рост | `img/step5-growth.png` | Аналитика (воронка, ретеншн) или рекламный кабинет Google Ads / Meta. Цифры можно замазать |
| 9. Мои приложения | `img/app-2speak.png`, `img/app-cryptolife.png`, `img/app-game2.png` | Иконки трёх приложений (квадрат, 512×512+) |
| 9. Мои приложения | — | Ссылки на страницы в сторах: QR сделаю сам |

Если на каком-то этапе скриншота нет — слайд работает и без него, клик просто убираем.

### Слайд 7 — Айсберг

| Где | Сейчас | Картинка |
|-----|--------|----------|
| Верхушка | 📱 | Телефон с приложением (или реальный скриншот приложения) |
| SDK | 🧩 | Кубики-пазлы, вставляемые в телефон |
| Аналитика | 📊 | График / воронка |
| Атрибуция | 🎯 | Нитка от рекламы к установке |
| MMP | 🔗 | Хаб, в который сходятся линии от рекламных сетей |
| Google Ads / Meta Ads | 📣 | Настоящие логотипы, не генерировать |
| Трафик | 🚰 | Кран, из которого льются человечки в воронку |
| Тест полного круга | 🔁 | Круговая стрелка с галочкой |
| Юнит-экономика | 💰 | Весы: стоимость пользователя против дохода с пользователя |
| По кругу | 🔄 | Можно оставить нарисованным кругом |

### Слайд 8 — Внимание

| Где | Сейчас | Картинка |
|-----|--------|----------|
| Бабушка из Бразилии + GPT | 👵💻 | Бабушка за ноутбуком, на экране чат и готовое приложение |
| Иконки приложений | фиолетовые квадраты | Можно оставить: одинаковость — это и есть смысл |
| Глаз | 👁 | Глаз или прожектор, который выхватывает одно приложение |
