# talk-2speak

Доклад на 10 минут на reveal.js 6.0.2. Работает полностью офлайн: без сервера, npm и интернета.

## Как открыть

Дважды щёлкните `index.html`. Лучше всего работает в Chrome.

- Слайды — прямо в `index.html`, внутри `<section>`.
- Заметки докладчика — в `<aside class="notes">` того же слайда. Там уже лежат тезисы сценария и подсказки, где кликать.
- Сценарий и тайминг — в `script.md`.

## Клавиши

| Клавиша | Действие |
|---------|----------|
| → / Пробел | Следующий шаг: внутри каждого слайда анимация идёт по клику |
| ← | Назад |
| F | Полный экран |
| S | Окно докладчика: заметки, следующий слайд, таймер |
| B или . | Пауза: чёрный экран |
| Esc или O | Обзор всех слайдов |

Если окно докладчика не открылось по S, разрешите браузеру всплывающие окна для этого файла.

## Картинки

Сейчас вместо картинок стоят эмодзи и пунктирные рамки. Список того, что нужно, и предложение по стилю — в `images.md`. Готовые файлы кладите в `img/`.

Видео, если понадобится, кладите в `video/` и вставляйте через `<video controls preload="none" src="video/....mp4">`.

## Экспорт в PDF

1. Откройте в Chrome `index.html?print-pdf`.
2. Cmd+P (Ctrl+P в Windows) → «Сохранить как PDF», раскладка «Альбомная», поля «Нет», включить «Фоновая графика».
3. Каждый шаг анимации становится отдельной страницей. Чтобы в PDF был только финальный вид каждого слайда, откройте `index.html?print-pdf&pdfSeparateFragments=false`.
4. Чтобы заметки попали в PDF, добавьте `&showNotes=true`.

## Структура

```
index.html   презентация (8 слайдов, шаги внутри по клику)
reveal/      reveal.js 6.0.2 (dist/ — собранные файлы, plugin/ — исходники плагинов)
img/         картинки и скриншоты
video/       видео
script.md    сценарий выступления
images.md    какие картинки нужны
```

`index.html` подключает собранные плагины из `reveal/dist/plugin/`. Папка `reveal/plugin/` — исходники из релиза, для показа она не нужна.
