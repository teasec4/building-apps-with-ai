## Локальный просмотр

Скачайте репозиторий и откройте `index.html` в современном браузере. Все файлы презентации включены в репозиторий; сервер, npm и интернет для локального просмотра не нужны.

Клавиши: `←` / `→` или пробел — листать, `F` — полный экран, `S` — заметки докладчика, `Esc` — обзор слайдов.

## Экспорт в PDF

Откройте `index.html?print-pdf&pdfSeparateFragments=false` в Chrome и выберите «Печать» → «Сохранить как PDF», альбомную ориентацию, поля «Нет» и фоновую графику.

## Материалы

`index.html` — презентация на Reveal.js; `script.md` — сценарий и тайминг; `img/` и `reveal/` — локальные ресурсы, необходимые для показа.
